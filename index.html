Git na prática

Anatomia do Repositório

O repositório Giovana_Study_Hub_TI foi organizado em pastas numeradas, que contam a história acadêmica de forma clara e navegável, e cada evolução passa pelo fluxo de versionamento do Git.

Estrutura de pastas

  • Giovana_Study_Hub_TI/
  • 01_Apresentacao_e_Perfil Quem sou eu: perfil, currículo e apresentação.
  • 02_Disciplinas_Cursadas Códigos, protótipos e artigos de disciplinas concluídas.
  • 03_Disciplinas_em_Curso Evidências em andamento, atualizadas a cada semana.
  • 04_Projetos_e_Certificados Projetos completos e certificações.
  • README.md

Boas práticas adotadas

  • Nomes numerados que definem uma ordem de leitura lógica.
  • Commits pequenos e descritivos que contam a evolução do trabalho.
  • README como porta de entrada para quem visita o repositório.
  • Separação por contexto: perfil, estudo e entrega em pastas distintas.
  • GitHub Pages publicando este portfólio diretamente do repositório.
