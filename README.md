## 📌 Sobre o Projeto

O **Study Hub** é uma plataforma desenvolvida como parte do desafio do **Bootcamp I**, concebida para documentar, organizar e versionar a trajetória acadêmica e técnica de **Giovana Amorim Campos** durante o 8º semestre da graduação em Ciência da Computação.

O projeto conecta o foco em **Engenharia de Software** (arquitetura, qualidade, testes e desenvolvimento estruturado) ao **Gerenciamento de Projetos** (planejamento, controle de processos, gestão de requisitos e métodos ágeis como Scrum e Kanban).

🌐 **Acesse a aplicação no GitHub Pages:** [https://giovanaamorim.github.io/Giovana_Study_Hub_TI/](https://giovanaamorim.github.io/Giovana_Study_Hub_TI/)

## 🗂️ Anatomia e Estrutura do Repositório

O repositório foi organizado em pastas numeradas, criando uma trilha navegável e sequencial que contextualiza cada fase da formação:

```text

│   ├── 📁 Interacao_Humano_Computador/  # Usabilidade, heurísticas e protótipos de UX
│   ├── 📁 Programacao_Dispositivos_Moveis/ # Aplicações mobile e ciclo de vida
│   ├── 📁 Seguranca_de_Dados/           # Códigos práticos de proteção e integridade
│   └── 📁 Sistemas_Operacionais/        # Gerenciamento de processos e concorrência
├── 📁 03_Disciplinas_em_Curso/          # Evidências do 8º semestre em andamento
